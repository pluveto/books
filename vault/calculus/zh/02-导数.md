# 导数

## 定义

> [!definition] 导数
> 若极限
> $$
> f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}
> $$
> 存在，则称 $f$ 在 $a$ 处**可导**，$f'(a)$ 是 $f$ 在 $a$ 处的**导数**。

几何上，$f'(a)$ 是曲线在点 $(a, f(a))$ 处切线的斜率。这里用到的极限概念见 [[01-极限#严格定义]]。

## 常见导数

| $f(x)$ | $f'(x)$ |
| --- | --- |
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |

## 数值验证

差商在 $h$ 很小时接近导数。下面的程序用中心差商检验 $\sin' = \cos$：

```ts
const derivative = (f: (x: number) => number, x: number, h = 1e-5): number =>
  (f(x + h) - f(x - h)) / (2 * h)

console.log(derivative(Math.sin, 0)) // ≈ 1 = cos(0)
```

> [!tip] 为什么用中心差商
> 中心差商的误差是 $O(h^2)$，单侧差商是 $O(h)$。同样的 $h$，前者准确得多。

## 链式法则

若 $g$ 在 $a$ 处可导，$f$ 在 $g(a)$ 处可导，则

$$
\frac{\dd}{\dd x} f\big(g(x)\big) \Big|_{x=a} = f'\big(g(a)\big)\, g'(a).
$$
