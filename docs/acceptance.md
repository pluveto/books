# Acceptance criteria

The publisher is done when every item below holds. "Verified by" names the test file and the test's title; items marked **Manual** have no automated check and say what a reviewer looks at.

## Known gaps

- A formula's accessible name is its TeX source, not spoken mathematics.
- Pages have no `og:image`.
- Without JavaScript there is no search and no dark theme.
- `ChapterRenderer` chooses its web or PDF plugin chain by a `kind` flag rather than by an output object.
