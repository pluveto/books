# Acceptance criteria

The publisher is done when every item below holds. "Verified by" names the test file and the test's title; items marked **Manual** have no automated check and say what a reviewer looks at.

## Authoring

| #   | Criterion                                                                                                                                                                                                                                                                                                                                                                       | Verified by                                                                                                                                                                                                                                                                                                                                                           |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | Links resolve with Obsidian's rules: exact vault path, then relative to the note, then a unique path suffix; names are case-insensitive; `#heading` matches heading text; aliases, embeds with size and Markdown links to notes work.                                                                                                                                           | `unit/file-index.test.ts` (all tests); `unit/render.test.ts` "wikilinks, Markdown links and embeds resolve with Obsidian's rules". **Manual:** the rules were compared with Obsidian's documentation, not with a running Obsidian.                                                                                                                                    |
| A2  | Anything that cannot be published faithfully stops the build with `vault/<file>:<line>: <reason>`: unknown or ambiguous links, missing headings, block references, note embeds, bad formulas, bad chapter names, nested or duplicate chapters, extra level-1 headings, invalid YAML, unknown frontmatter keys (with a suggestion), unsupported languages, low-contrast colours. | `unit/series-reader.test.ts` "series.md problems name the key", "book.md problems are caught before anything is written", "frontmatter problems point at the key's line and suggest the intended key", "chapter problems point at the file and line"; `unit/render.test.ts` "broken formulas fail with the note and line", "broken links fail with the note and line" |
| A3  | A failed build never damages the previous output, and the build refuses to replace a folder it did not create.                                                                                                                                                                                                                                                                  | `build/cli.test.ts` "build writes the site and a content error exits 1 naming the file", "a failure after rendering leaves the previous site byte-for-byte", "build refuses to replace a folder it did not create"                                                                                                                                                    |
| A4  | TeX macros are declared once per book; MathJax, XeLaTeX and Obsidian's preview (`npm run preamble`) all read them.                                                                                                                                                                                                                                                              | `unit/values.test.ts` "macros become a MathJax table and keep their TeX source"; `pdf/pdf.test.ts` "Pandoc reads formulas as math and footnotes as notes"; `unit/preamble.test.ts` "the Obsidian preamble is the union of every book's macros"                                                                                                                        |
| A5  | `npm ci && npm run check && npm test && npm run build` works unchanged on Windows, macOS and Ubuntu with only Node.js 22.12+.                                                                                                                                                                                                                                                   | CI job `build` on all three systems                                                                                                                                                                                                                                                                                                                                   |

## Rendering

| #   | Criterion                                                                                                                                                            | Verified by                                                                                                                                                              |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| R1  | Every formula is SVG in the HTML; no page ships a math or highlighting runtime.                                                                                      | `build/site.test.ts` "formulas and code are finished at build time"                                                                                                      |
| R2  | Formulas have an accessible name (their TeX source).                                                                                                                 | `unit/render.test.ts` "math is typeset to SVG at build time and labelled with its TeX"; axe in `e2e/quality.spec.ts` "… meets WCAG 2.1 AA"                               |
| R3  | Callouts (including foldable ones), highlights, comments, footnotes and tables render through Quartz's plugins and GFM, with interface text in the page's language.  | `unit/render.test.ts` "callouts, including foldable ones with math in the title, come from Quartz", "highlights, comments, footnotes and tables follow Obsidian and GFM" |
| R4  | Code is highlighted at build time with light and dark colours that meet WCAG AA.                                                                                     | `build/site.test.ts` "formulas and code are finished at build time"; axe in both themes                                                                                  |
| R5  | Two builds of the same vault are byte-identical except Pagefind's index, which Pagefind does not write reproducibly; the indexes cover the same languages and pages. | `build/site.test.ts` "two builds are byte-identical outside Pagefind, whose index is equivalent but not reproducible"                                                    |
| R6  | The PDF typesets formulas and footnotes natively, with the book's macros and chapter labels in the edition's language, and contains no TeX source.                   | `pdf/pdf.test.ts` "Pandoc reads formulas as math and footnotes as notes", "a typeset PDF contains no TeX source" (CI job `pdf` requires the full toolchain)              |

## Site

| #   | Criterion                                                                                                                                                                                                          | Verified by                                                                                                                                                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | Pages: language entry (`/`), catalog per language, cover page per edition with full contents, one page per chapter, bilingual 404.                                                                                 | `build/site.test.ts` "every page of every edition is built"; `e2e/quality.spec.ts` "unknown paths get the bilingual 404 page"                                                                                                          |
| S2  | Every internal link, asset and `#fragment` resolves; nothing is requested from another origin.                                                                                                                     | `build/site.test.ts` "every internal link, asset and fragment resolves"; `e2e/quality.spec.ts` "the site requests nothing from other origins"                                                                                          |
| S3  | Indexable pages have title, description, canonical URL and Open Graph tags, and reciprocal `hreflang` with one `x-default`; the entry page and 404 are `noindex`; `sitemap.xml` lists exactly the indexable pages. | `build/site.test.ts` "indexable pages carry title, description, canonical and Open Graph tags; the rest are noindex", "hreflang alternates of every indexable page are reciprocal", "sitemap, robots and search index are published"   |
| S4  | The language switch goes to the same chapter in the other language and is remembered; `/` follows the saved choice, then the browser language.                                                                     | `build/site.test.ts` "the language switch keeps the chapter"; `e2e/reading.spec.ts` "switching language keeps the chapter and is remembered", "the entry page follows a saved choice, then the browser language"                       |
| S5  | Search works per language, opens with `/` or Ctrl/⌘+K, downloads nothing until opened, and links under the site's base path.                                                                                       | `e2e/reading.spec.ts` "search finds chapters in the page's language", "search downloads nothing until it is opened"; `build/site.test.ts` "sitemap, robots and search index are published"                                             |
| S6  | The sidebar shows the chapters and the current chapter's sections, highlights the section in view, and is a drawer on phones that closes with Escape and returns focus.                                            | `e2e/reading.spec.ts` "the sidebar follows the section being read", "the contents drawer opens from the header and closes with Escape"                                                                                                 |
| S7  | Light and dark themes follow the system until the reader chooses; the choice persists and is applied before any script bundle runs.                                                                                | `e2e/reading.spec.ts` "the theme toggle wins over the system and persists", "a saved theme is applied before the script bundle runs"                                                                                                   |
| S8  | Each book uses its own accent colour; the entry page, catalogs and 404 use the series colour.                                                                                                                      | **Manual:** screenshots of a catalog, a cover and a chapter in both themes                                                                                                                                                             |
| S9  | Every tested page meets WCAG 2.1 AA (axe) in both themes on desktop and phone, has no console errors and no horizontal scrolling.                                                                                  | `e2e/quality.spec.ts` "… meets WCAG 2.1 AA", "… loads without errors or horizontal scrolling"                                                                                                                                          |
| S10 | Deep links land below the sticky header; headings have hover anchors; code blocks have a copy button; foldable callouts work from the keyboard.                                                                    | `e2e/reading.spec.ts` "a deep link lands below the sticky header", "code blocks can be copied", "a foldable proof opens from the keyboard"; `unit/render.test.ts` "headings get the outline's ids and the title is left to the layout" |
| S11 | The same build works under a sub-path (GitHub Pages project site) and at a domain root.                                                                                                                            | `build/site.test.ts` builds under `/books/`; the browser tests build at `/`                                                                                                                                                            |
